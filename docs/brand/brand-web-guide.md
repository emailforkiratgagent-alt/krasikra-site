# Фирменный стиль «Хозяин Камчатки» для сайта

Источник: брендбук ARTSTYLE, 2020 (84 стр.). Выжимка того, что нужно для веба.

## Платформа бренда (для тона текстов и визуала)
- Позиционирование: сеть специализированных экспертных магазинов рыбных деликатесов, продвигающая культуру потребления на новый уровень.
- Характер: брутальный, надёжный, профессионал.
- Ценности: экспертиза, гурманство, традиции и доверие.
- Эмоциональные преимущества: удовольствие, престиж.
- Ключевые преимущества для сайта: первые специализированные магазины икры в Красноярске; самый широкий ассортимент икры; бесплатные дегустации; собственное производство; «не понравился продукт — обменяем или вернём деньги».
- ЦА: «вьющие гнездо», средний и «элегантный» возраст.

Контраст (WCAG): синий на белом 13.2 и на бежевом 9.7 — для любого текста. Икорный на белом 4.45 — только крупный текст и кнопки с белым текстом от 18px bold; для мелкого текста и ссылок `#C2321F` (5.6). Икорный на синем 3.0 и на бежевом 3.3 — только декор и крупные элементы, не текст.

## Шрифты
- Фирменный: **DIN Pro** — Regular/Medium для текста, Bold/Black для заголовков. Коммерческий, для сайта нужна веб-лицензия.
- Надпись «ХОЗЯИН КАМЧАТКИ» в логотипе — специально нарисованные буквы, не шрифт: использовать только как SVG.
- Если веб-лицензии DIN Pro не будет — бесплатная замена с кириллицей близкого характера (подобрать и согласовать на этапе дизайна).

## Логотип
- Основной блок: медведь над вулканами + «ХОЗЯИН / КАМЧАТКИ» с волнами (`logo-main.svg`).
- Горизонтальный блок — для узких горизонтальных мест, в вебе — шапка сайта (`logo-horizontal.svg`).
- Знак «Медведь» без надписи — редко (`logo-sign.svg`): фавикон, аватар, иконка приложения.
- Допустимые фоны: белый, бежевый, синий (инверсия), монохром. Запрещено: нефирменные шрифты и цвета, контур, наклон, пёстрые фоны и фото, изменение пропорций.
- Минимальная высота основного блока в печати 18 мм; охранное поле — по брендбуку (модуль «х»).

## Фотостиль
Четыре группы: текстуры (бетон, тёмное дерево, тёмный камень), территория Камчатки (океан, вулканы, маяк), медведь/рыба/чайки, продукт. Продукт снимается крупно на тёмных или бетонных фонах, сочный, «икорный» акцент. Цвет фото — холодный, сдержанный, с тёплым акцентом продукта.

## Принципы сайта и соцсетей (раздел 9)
- Шапка с логотипом, крупный баннер с продуктом (икра), ряд круглых иконок категорий, блок «О компании», паттерн волн внизу.
- Соцсети: тёмные фото продукта, бежевые плашки, обложки актуального — синие с белой графикой.

## Магазины
Оформление: синие стены с белой графикой, фриз «ИКРА · РЫБА · МОРЕПРОДУКТЫ» на бежевом, дерево. Сайт должен узнаваться как «тот же магазин».
